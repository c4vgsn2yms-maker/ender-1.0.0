# Ender 1.0.0

A playable browser-based 3D platformer foundation with switchable first-person and third-person cameras.

## Play

Once GitHub Pages finishes deployment:

https://c4vgsn2yms-maker.github.io/ender-1.0.0/

## Controls

- **WASD** — move
- **Space** — jump
- **Shift** — sprint
- **Mouse** — look
- **V** — toggle first-person / third-person
- **R** — reset to the current spawn
- **Esc** — release the mouse

## Current base

- Original 3D platform course
- Third-person platforming camera
- First-person mode
- Mouse-look and camera-relative movement
- Jumping, sprinting, gravity and platform collisions
- Moving platforms
- Sky-shard collectibles
- Hazard surfaces and falling resets
- Roaming enemies that can be stomped
- Finish portal and run timer
- Responsive HUD
- WebGL fallback message
- Automatic GitHub Pages deployment

The current art is intentionally lightweight/procedural so gameplay can be iterated before custom characters, environments, animation rigs, audio and production assets are added.
